# kavtor brand assets

Original AI-assisted concept with clean vector contour artwork. The exact product spelling is **kavtor**.

Use `logo.svg` on light surfaces, `logo-on-dark.svg` on dark surfaces, and
`logo-monochrome.svg` for one-colour printing. SVG artwork uses outlines and
has no font dependency. PNG exports have transparent backgrounds.

Accent: `#20b9ad`. Main dark colour: `#141820`. Do not stretch the artwork.
Leave at least the height of one slider cap around the logo. The concept PNG
is retained as design provenance; use the vector master for print.

Licensed under GNU GPLv3, matching the project.

For A4 labels, choose A4 paper, no extra page margins, and Actual size / 100%. The sheet already contains print-safe margins.
